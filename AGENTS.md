# AGENTS.md — photo-booth

Modern rebuild of [`IEvangelist/IEvangelist.PhotoBooth`](https://github.com/IEvangelist/IEvangelist.PhotoBooth) — a kiosk-style photo booth (snap N webcam frames → stitch animated GIF → upload → SMS share link) on a 2026 stack.

## Stack

| Concern | Choice |
|---|---|
| Orchestrator | **Aspire** TypeScript AppHost (`apphost.ts`) |
| Frontend | **Angular** (latest stable, standalone components, signals) at `apps/web` |
| API | **ASP.NET Core minimal API** on **.NET 10 / C# 13 preview** at `apps/api` |
| Background | **Azure Functions (Node, TypeScript v4)** at `apps/functions` (queue-triggered) |
| Storage (local) | **Azurite** as an Aspire-managed container — Blob + Queue + Table |
| Realtime | ASP.NET Core **SignalR** hub hosted in the API |
| SMS | Provider abstraction — **ACS** + **Twilio** + **Log** (offline dev) selected via `SMS_PROVIDER` |

## Run commands

From the repo root:

```powershell
# Restore everything (one-time-ish)
dotnet restore .\apps\api\PhotoBooth.Api.csproj
npm install
npm --prefix .\apps\functions install
npm --prefix .\apps\web install

# Start the whole distributed app (Aspire orchestrates Azurite + API + Functions + Web)
aspire start
```

The Aspire dashboard URL is printed by the CLI.

## Conventions

- Branches use the `dapine/` prefix. Default trunk is `main`.
- All commits include the trailer:
  `Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>`
- C# is **.NET 10 / C# 13 preview** everywhere.
- Don't hand-edit `.modules/*.ts` — those are regenerated by `aspire add`. Use the `aspire` skill if you need to touch them.
- Don't commit `local.settings.json`, `.env`, or any provider credentials. ACS / Twilio / Storage keys are passed via Aspire parameters or environment.
- Webhook from Functions → API is gated by a shared-secret header (`X-Internal-Auth`) injected by the AppHost.

## Status flow

```
queued → stitching → uploaded → sending → sent
                        \         \
                         \         → sms_failed (share URL still valid)
                          → stitch_failed (hard error)
```

The Table row is authoritative. SignalR is the live overlay; `JoinCapture(captureId)` always replies with the current snapshot first.
